## 一、项目定位

TripWise 是一款 AI 旅行规划 Web 应用：用户选择目的地后，由大模型生成带时间线、交通建议、景点介绍的行程，并提供景点图片、地图导航与 AI 旅行顾问对话。**本项目按长期落地产品推进，非一次性演示。**

## 二、当前工程进度（已完成）

### 2.1 功能清单

| 模块 | 状态 | 说明 |
|------|------|------|
| AI 路线生成 | ✅ 已上线 | 任意城市输入目的地即生成多日行程（时间/景点/交通方式/描述） |
| 离线精选路线 | ✅ 已上线 | 北京等热门城市内置人工精选路线，不依赖网络与 AI 额度 |
| AI 旅行顾问 | ✅ 已上线 | 对话式问答（美食、避坑、行程调整建议） |
| 景点图片 | ✅ 已上线 | 本地预置图 + 在线生成图兜底 + 缓存；无图时优雅降级为占位样式 |

### 2.2 技术与部署现状

- **架构**：纯静态前端（HTML/CSS/JS，无构建依赖），AI 调用为浏览器直连模型服务
- **AI 服务商**：魔搭 ModelScope API-Inference（模型 Qwen3.5-35B-A3B），**每日免费额度（约 2000 次调用/天，单模型约 200 次）**，账号资质已就绪（已绑阿里云+邮箱验证）
- **部署**：GitHub Pages 已上线，国内可达；全站端到端实测通过（AI 路线生成、图片渲染、顾问对话均验证正常）
- **代码仓库**：github.com/HanJiang-GuiYang/TripWise

### 2.3 已知限制（落地前必须处理）

| # | 限制 | 影响 | 解决阶段 |
|---|------|------|----------|
| 1 | API 密钥暴露在前端（每个访客可见） | 免费额度被陌生人刷光；换付费后直接烧钱（已实际发生过） | 阶段一 |

| 4 | 无内容安全过滤 | 用户输入直通大模型，公开运营有合规风险 | 阶段一 |

## 三、落地路线图（三阶段）

### 阶段一：上线准备（从"能用"到"敢公开"）

- **后端代理**：函数计算 FC / 云函数（约 50 行代码），密钥存服务端环境变量；顺带获得：接口限流、内容安全过滤（阿里云绿网类服务）、更换服务商前端零改动
- **域名 + ICP 备案**：备案免费但**必须实名主体**（未成年人需以家长名义注册与备案，周期 1~3 周，此为非资金硬门槛）
- **合规基线**：接入已完成备案的大模型服务商（当前服务商已备案）+ 页面标注"内容由 AI 生成" + 隐私政策页
- **地图商用**：高德 Key 从个人开发者升级为企业认证（认证免费，配额提升）

### 阶段二：产品化（从"公开"到"可运营"）

- 用户账号体系（建议先做邮箱验证码登录，避开短信成本；微信登录需企业资质）
- 云端数据库：行程持久化、分享链接、收藏同步
- 结果缓存：同城市热门路线服务端缓存复用（AI 成本可降 50%+）
- 数据埋点：留存/生成转化率，指导产品迭代

### 阶段三：规模化（用户破万后）

- 独立数据库实例 + 只读缓存、AI 请求队列与削峰
- 付费模式接入（微信支付/支付宝商户，均需营业执照——届时决定是否注册个体户，代办约 ¥0~500）
- 视监管要求评估自研算法备案（初期借道已备案服务商可规避）

## 四、预算模型

### 4.1 计算公式

```
月总成本 = AI 调用成本 + 服务器成本 + 数据库成本 + 域名摊销 + CDN/杂项

AI 调用成本 = 日活用户 × 人均日生成次数 × 单次 token 量 × 30 × token 单价
  · 单次行程生成 ≈ 3,000~4,000 tokens（输入 1.5~2.5k + 输出 1.5~2k）
  · 单次顾问对话 ≈ 500~1,000 tokens
  · 轻量模型现价参考：输入 ¥1~2/百万 token，输出 ¥2~8/百万 token
  → 单次行程生成成本 ≈ ¥0.005~0.02（即"一次几分钱"）

服务器成本 = 函数计算按量（低流量近 ¥0，10 万请求约 ¥10~20/月）
数据库成本 = 起步用免费/最低规格（¥0~100/月）
域名 = ¥30~80/年（.cn / .com）
```

### 4.2 三档场景估算

| 场景 | 规模 | AI 成本 | 基础设施 | 月合计 | 备注 |
|------|------|---------|----------|--------|------|
| **A. MVP 公测** | ≤100 用户/日 | ¥0（魔搭免费额度覆盖） | ¥0~5（域名摊销） | **≈ ¥0~10/月** | 当前架构+免费额度即可支撑，唯一风险是被薅额度 |
| **B. 成长期** | 1,000 用户/日（约 3 万次生成/月） | ¥150~600 | ¥100~250（FC+数据库+CDN） | **≈ ¥300~900/月** | 转付费 API + 后端代理生效 |
| **C. 小规模运营** | 10,000 用户/日 | ¥1,500~4,500 | ¥500~1,200 | **≈ ¥2,000~6,000/月** | 上缓存后 AI 成本可压 40~60% |

### 4.3 一次性/隐性成本

| 项目 | 金额 | 说明 |
|------|------|------|
| ICP 备案 | ¥0 | 免费，但要家长实名主体 + 1~3 周周期 |
| 地图企业认证 | ¥0 | 免费 |
| 个体户注册（若将来接支付） | ¥0~500 | 代办费，自己跑登记免费 |
| 内容安全审核 API | 约 ¥0.001~0.005/次 | 阶段一再评估，初期可用服务商自带过滤 |
| 敏感期（重大会议等） | 波动 | 国内云厂商可能临时收紧备案站点策略，预留心理预期 |

### 4.4 降本手段（按性价比排序）

1. **服务端结果缓存**：同城同季路线高度复用，AI 成本最大头可砍半以上
2. **模型分级**：草稿/预览用最小免费模型，最终版用大模型
3. **输出瘦身**：约束 JSON 字段与长度（已做），token 直降
4. **错峰免费池**：魔搭免费额度作为日常兜底，付费 API 只做溢出承接

## 五、落地需要准备什么（给策划的行动清单）

1. **主体**：确定以谁的名义注册云账号/域名/备案（未成年人项目 → 家长）
2. **预算审批**：阶段 A 几乎零成本可先行；建议按场景 B 预留 **¥1,000/月** 上限授权，避免届时层层追加
3. **产品决策**（工程等待输入）：
   - 目标用户与首发城市范围（影响预置内容工作量）
   - 是否需要账号体系（不需要则阶段二可整体后移）
   - 商业化时间点（决定个体户/执照办理时机）
4. **合规文案**：隐私政策、AI 生成声明、用户协议模板（工程可起草初稿）

## 六、风险登记

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 免费模型下架/额度政策收紧 | 中 | 服务降级 | 提供商可插拔（config 一行切换），备选池：智谱/硅基流动/OpenRouter |
| 前端密钥被薅（现状） | 高 | 额度耗尽、临时不可用 | 阶段一后端代理根治；现阶段被薅则换 key，5 分钟恢复 |
| 备案主体问题 | 中 | 无法国内正式运营 | 提前锁定家长配合，备案与开发并行 |
| AI 输出质量波动 | 中 | 口碑 | 提示词已结构化约束 + 离线精选路线兜底 |
